# QuantumView

**Visualize impact. Predict engagement. Learn with entertainment.**


## Overview
QuantumView enables education researchers and media producers to evaluate how entertainment content impacts learning and behavioral outcomes.


## Features
- Real-time analytics
- Predictive behavior modeling
- Viewer engagement tracking
- Time-series optimized storage
- D3.js dashboards


## Technologies Used
- Python 3.10+
- FastAPI
- Airflow
- TimescaleDB
- React.js
- D3.js


## Getting Started
1. Clone the repo
2. Run `docker-compose up`
3. Access dashboard at `localhost:3000`
4. API available at `localhost:8000/docs`
